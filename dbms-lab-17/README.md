# Description of the Project

# 

# This Car Rental System has been created in PHP and MySQL with XAMPP. This system allows users to choose customers and cars, enter rental dates, store rental information, and generate a rental report.

# 

# Database Connection and Queries

# 

# The db.php file connects PHP to the MySQL database carrental\_db using mysqli\_connect().

# 

# db.php is included in both rental.php and report.php files to make database connection.

# 

# The rental form fetches customer and car information from database using SQL SELECT queries.

# 

# On submission of the form, SQL INSERT prepared query stores the rental transaction in the database.

# 

# report.php page combines the customer, car, and rental table with SELECT query and INNER JOIN.

# 

# The report shows customer name, car model, registration number, start date and end date.

# 

# Running of the Project

# 

# Install XAMPP and start Apache and MySQL.

# 

# Import carrental\_db.sql through phpMyAdmin.

# 

# Place the project folder in the C:\\xampp\\htdocs directory.

# 

# Launch http://localhost/dbms-lab-17/rental.php in the browser.
